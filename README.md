# MUDIE-Recomendador-cinematogr-fico
MUDIE es un recomendador cinematográfico conversacional que soluciona la indecisión al elegir qué ver. A diferencia de los sistemas tradicionales, traduce el estado de ánimo o necesidad emocional expresada por el usuario en lenguaje natural y la vincula con una selección curada, ofreciendo recomendaciones personalizadas y reflexivas.
